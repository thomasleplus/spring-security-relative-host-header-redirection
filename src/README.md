# Source

Maven sources for a Spring Boot app demonstrating relative Host-header
redirection behaviour in Spring Security.

- `main/java/org/leplus/rhhr/RhhrApplication.java` — the application entry point.
- `main/java/org/leplus/rhhr/SecurityConfig.java` — the Spring Security setup
  being demonstrated.
- `main/resources/application.properties` — configuration.
- `test/java/org/leplus/rhhr/` — JUnit tests.

Run with `./mvnw spring-boot:run`.
